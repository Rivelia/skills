# Relaunching a dead merge-ready.mjs run

Never resume it with `resumeFromRunId`, whatever the harness suggests. Each round's review misses the cache partway through and re-runs live against a tree that already holds the fixes, so the loop reports `converged` on a round that fixed nothing. Relaunch instead: redo steps 1 to 5 with the same scope and the dead run's `base`, recovered as below rather than recomputed; the workflow reads the launch state afresh, so the relaunch loses only the stage that was in progress.

Every stage commits its own changes, so the tree is clean unless the run died mid-stage. When `git status --porcelain` lists anything, show it to the user before step 2 commits it: it is a dead agent's partial work, not the user's.

Take `base` from the launch args in the dead run's `journal.jsonl`. When that cannot be found, step 1 recomputes the same `base` for `branch`, `unpushed` and a `since` given as a sha or tag, but not for `uncommitted` or a commit-ish relative to HEAD such as `HEAD~3`: against the current HEAD, `git rev-parse HEAD` points past the work and the dead run's commits, leaving nothing to review, and `HEAD~3` names one of the dead run's commits. Take instead the HEAD the first run launched on, since a relaunch keeps the first run's `loopStart` and a later run's `wip:` commit holds a dead agent's work: the first run's `loopStart` recovered below, or its parent when that `loopStart` is the `wip:` commit the first run's step 2 made. For `uncommitted`, that commit is `base`; for a relative commit-ish, resolve it with that commit in place of `HEAD` (`git rev-parse '<commit>~3'`). When that `loopStart` cannot be found, ask the user which commit the work started from and stop.

For every scope except codebase, which takes no `loopStart`, set it to the dead run's own `loopStart` rather than HEAD, so the commits it made are set apart from the author's: take it from the launch args in its `journal.jsonl`, or, when that cannot be found, the `wip:` commit step 2 made (`git log --format='%h %s' -n 50` lists it), or the parent of the run's earliest commit. Confirm it with `git merge-base --is-ancestor <loopStart> HEAD`. After several dead runs, keep the first run's `loopStart`. When none of these can be found, use HEAD and tell the user the dead run's commits will read as the author's.
